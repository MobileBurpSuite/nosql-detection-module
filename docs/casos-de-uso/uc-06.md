# UC-06: Generar Reporte de Vulnerabilidad

## 1. Descripción Breve
Consolida los resultados analizados y exporta un informe técnico estructurado con las evidencias de las vulnerabilidades NoSQL detectadas.

## 2. Actores
* **Primario:** Analista de Seguridad

## 3. Precondiciones
* Debe haberse completado la evaluación de respuestas (UC-05).

## 4. Flujo Principal (Normal)
1. El analista solicita la generación del reporte final.
2. El generador de reportes (`C6`) recopila los hallazgos positivos desde el registro de resultados.
3. Se estructura el informe consolidando la fecha, el dictamen final y las evidencias técnicas.
4. El sistema exporta el reporte en formato legible para el analista.

## 5. Postcondiciones
* Se genera el entregable final de auditoría del módulo.
