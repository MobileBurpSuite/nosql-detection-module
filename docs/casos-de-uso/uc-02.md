# UC-02: Cargar Diccionario de Payloads BSON

## 1. Descripción Breve
Permite cargar y parsear los vectores de ataque estáticos orientados a operadores BSON desde el sistema de archivos hacia la memoria RAM del módulo.

## 2. Actores
* **Primario:** Analista de Seguridad
* **Secundario:** Sistema de Archivos

## 3. Precondiciones
* Los archivos de diccionarios (`.json`/`.yaml`) deben encontrarse estructurados en la ruta configurada del sistema.

## 4. Flujo Principal (Normal)
1. El analista solicita la carga del diccionario de payloads.
2. El sistema (a través de `C2: GestorDiccionarios`) se comunica con el sistema de archivos mediante el lector (`F3`).
3. Se leen los archivos físicos (`E1`) y se indexan los vectores de ataque en la entidad de registro en memoria RAM (`E5`).
4. **[<<include>>]** El sistema invoca automáticamente a **UC-03 (Seleccionar Parámetros Candidatos)** para cruzar las firmas sintácticas con el cuerpo base de la solicitud.
5. El sistema notifica al analista el éxito de la indexación de payloads.

## 5. Flujos Alternativos
* **2a. Archivo no encontrado o corrupto:**
  * 2a.1. El sistema detecta un error de sintaxis o ausencia del archivo de diccionarios.
  * 2a.2. Se notifica el error crítico al analista y se aborta la inicialización del motor.

## 6. Postcondiciones
* Los payloads BSON quedan indexados y disponibles en memoria RAM para el motor de mutación.
