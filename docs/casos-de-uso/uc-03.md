# UC-03: Seleccionar Parámetros Candidatos

## 1. Descripción Breve
Analiza heurísticamente el cuerpo base de la solicitud HTTP para aislar y seleccionar las claves y parámetros que son susceptibles a recibir inyecciones NoSQL.

## 2. Actores
* **Primario:** Analista de Seguridad (de forma indirecta vía UC-02)

## 3. Precondiciones
* Debe existir un contexto de ejecución previo con un cuerpo base válido (UC-01).
* Debe haberse ejecutado la solicitud de carga de diccionarios (UC-02).

## 4. Flujo Principal (Normal)
1. El controlador heurístico (`C3`) evalúa el contenido JSON de la entidad de contexto de ejecución (`E2`).
2. Se identifican las claves (como campos de usuario, contraseñas, filtros de búsqueda) susceptibles a evaluación NoSQL.
3. El sistema genera la entidad de memoria de **Parámetros Candidatos** (`E6`).
4. Se retorna el control al flujo principal de inicialización.

## 5. Postcondiciones
* Quedan definidas las llaves y parámetros clave sobre los cuales operará el motor de mutaciones.
