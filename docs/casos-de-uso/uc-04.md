# UC-04: Mutar Solicitudes y Ejecutar Pruebas

## 1. Descripción Breve
Orquesta la generación masiva de solicitudes mutadas combinando los parámetros candidatos con los payloads BSON del diccionario para ejecutar las pruebas de penetración contra la API objetivo.

## 2. Actores
* **Primario:** Analista de Seguridad
* **Secundario:** Servidor (API / MongoDB)

## 3. Precondiciones
* El entorno de pruebas debe estar configurado (UC-01).
* Los diccionarios y parámetros candidatos deben estar cargados (UC-02 y UC-03).

## 4. Flujo Principal (Normal)
1. **[<<include>>]** El sistema verifica obligatoriamente que el entorno de pruebas (UC-01) esté activo.
2. El analista inicia la ejecución de la batería de pruebas.
3. El motor de mutación (`C4`) inyecta los payloads BSON sobre los parámetros candidatos.
4. Se envían secuencialmente las peticiones HTTP mutadas al servidor a través del cliente HTTP (`F2`).
5. El sistema recolecta los resultados crudos de cada iteración en el registro de resultados (`E4`).

## 5. Postcondiciones
* Se genera la traza completa de ejecuciones y respuestas HTTP obtenidas tras la campaña de pruebas.
