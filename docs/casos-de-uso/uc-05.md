# UC-05: Analizar Respuestas y Evaluar Comportamientos

## 1. Descripción Breve
Compara las respuestas obtenidas durante la ejecución de las pruebas mutadas frente a los parámetros de la línea base para detectar anomalías o indicios de vulnerabilidad.

## 2. Actores
* **Primario:** Analista de Seguridad

## 3. Precondiciones
* Deben haberse ejecutado las pruebas de mutación (UC-04).
* Debe existir el registro de la línea base (UC-01).

## 4. Flujo Principal (Normal)
1. El evaluador de respuestas (`C5`) procesa las trazas de resultados (`E4`).
2. Se contrasta el código de estado HTTP, la longitud del cuerpo y el contenido de la respuesta frente a la línea base (`E3`).
3. El sistema califica si la mutación provocó un bypass lógico o una respuesta anómala.
4. Se marcan los registros correspondientes como positivos de vulnerabilidad.

## 5. Postcondiciones
* Los hallazgos quedan clasificados y listos para la consolidación del reporte.
