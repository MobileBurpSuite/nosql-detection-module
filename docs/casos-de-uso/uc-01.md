# UC-01: Configurar Entorno de Pruebas

## 1. Descripción Breve
Permite al Analista de Seguridad configurar la URL objetivo, método HTTP, cabeceras y proxy de conexión, midiendo y registrando la latencia de la línea base del servidor antes de iniciar el ciclo de pruebas.

## 2. Actores
* **Primario:** Analista de Seguridad
* **Secundario:** Servidor (API / MongoDB)

## 3. Precondiciones
* El sistema debe contar con acceso de red activo hacia la API REST objetivo.
* El analista debe tener acceso a la interfaz de línea de comandos (CLI) o panel de control.

## 4. Flujo Principal (Normal)
1. El analista solicita la configuración inicial del entorno indicando el objetivo.
2. El sistema (a través de `C1: GestorConfiguracion`) captura los parámetros y crea/actualiza el contexto de ejecución (`E2`).
3. El sistema prepara la solicitud HTTP base y la envía al servidor objetivo a través del cliente HTTP (`F2`).
4. El servidor procesa la solicitud y emite una respuesta HTTP junto con el tiempo de latencia medido.
5. El sistema analiza la respuesta, registra la línea base (`E3`) y confirma la configuración exitosa al analista.

## 5. Flujos Alternativos
* **3a. Error de Conectividad / URL Inalcanzable:**
  * 3a.1. El cliente HTTP no recibe respuesta del servidor o arroja un código de error de red.
  * 3a.2. El sistema notifica el fallo de conexión al analista y aborta el guardado de la línea base.

## 6. Postcondiciones
* El contexto de ejecución queda plenamente establecido en memoria RAM.
* Se almacena el registro de la línea base con el código HTTP y la latencia de referencia (`T_linea_base`).
