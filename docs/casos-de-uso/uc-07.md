# UC-07: Detección por Tiempo / Time-Based

## 1. Descripción Breve
Extiende las capacidades de análisis evaluando la latencia temporal de las respuestas del servidor para detectar vulnerabilidades de Inyección NoSQL ciega basadas en retardos (*Time-Based*).

## 2. Actores
* **Primario:** Analista de Seguridad
* **Secundario:** Temporizador

## 3. Precondiciones
* Debe haberse ejecutado una prueba de mutación con payloads de retardo temporal (Categoría D).

## 4. Flujo Principal (Normal)
1. **[<<extend>>]** Este caso de uso extiende opcionalmente a **UC-05 (Analizar Respuestas)** cuando se emplean cargas de tiempo.
2. El detector temporal (`C7`) interactúa con el componente de tiempo (`F4`).
3. Se mide la diferencia estricta entre el tiempo de respuesta de la solicitud mutada y el umbral de la línea base (`T_respuesta - T_linea_base >= Umbral_Sleep`).
4. Si el retardo supera el parámetro configurado, se califica la existencia de una inyección NoSQL ciega por tiempo.

## 5. Postcondiciones
* Se registra el hallazgo de vulnerabilidad basada en tiempo en el sistema de resultados.
